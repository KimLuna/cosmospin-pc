# tripleS Cosmo Tool — v4 + SPIN

## 실행
1. 압축을 풉니다.
2. `START.bat`을 더블클릭합니다.
3. 처음 한 번만 실행 프로그램을 다시 만들고, 이후에는 바로 열립니다.

기존 v4 폴더에 덮어써도 됩니다. 새 SPIN 빌드인지 자동 확인해서 필요한 경우 한 번만 다시 빌드합니다.

## 전송
기존 v4와 같습니다.
- tripleS Objekt만 표시
- 카드별 실제 시리얼 직접 선택
- 여러 장 순차 전송
- 매 장마다 체인 Transfer 로그 확인 후 다음 장 진행

## SPIN
상단 `SPIN` 탭에서 사용합니다.

1. 서버의 Spin Ticket / 다음 충전시간 / Spin 가능 시즌을 확인합니다.
2. 소모할 Objekt의 실제 시리얼을 직접 선택합니다.
3. `이 시리얼로 SPIN 1회`를 누릅니다.
4. 마지막 경고를 확인합니다.
5. `서버에서 이번 SPIN 결과 받기`를 한 번 누릅니다.
6. Cosmo 서버가 확정해서 내려준 16칸 전체 결과를 표시하고, 실제 획득 Objekt로 표시된 칸을 강조합니다.

### 보수 모드
- 자동 연속 SPIN 없음
- 클라이언트 임의 칸 선택 없음
- 재굴림 없음
- 결과 선조회 없음
- 실패 요청 자동 재전송 없음
- Ticket 수를 로컬에서 만들거나 계산하지 않음
- 서버가 `spinable`로 표시한 시즌만 노출
- `Transferable`인 Objekt만 선택 가능

이번 FIX4는 결과 확정 요청에서 임의 `selectedIndex`를 보내던 FIX2 동작을 제거하고, 발급된 `spinId` 기준으로 결과를 요청합니다. 결과 요청 실패 시 자동 재시도하지 않고 공식 Cosmo 앱에서 이어서 완료하도록 안내합니다.

이번 버전은 실제 iPhone Cosmo 2.49.0에서 캡처한 **Spin Ticket 1회 흐름**만 연결했습니다. Point 잔액과 600P 가격은 표시하지만, Point 결제 SPIN은 별도 결제 요청 흐름이 캡처되지 않아 실행하지 않습니다.

## 처음 테스트할 때
복구가 어려운 기능이므로 첫 SPIN은 아끼지 않는 시리얼 1장으로만 확인하는 것을 권장합니다.

## FIX5 변경사항
- 새로고침 시 실행 중인 로컬 로그인 세션 자동 복원
- SPIN 16칸 직접 선택 UI 복구
- 칸 선택 즉시 결과 요청 1회 전송, 성공 시 16칸 전체 공개
- 내가 선택한 칸과 실제 획득 Objekt를 동시에 표시
- 고정 3.5초/8초 대기 제거
- SPIN 화면 UI 정리
